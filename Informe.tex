\section{Resumen}

Docker es una plataforma de código abierto que permite a los desarrolladores y administradores de sistemas construir, empaquetar y distribuir aplicaciones en contenedores. Los contenedores son unidades de software que incluyen todo lo necesario para que una aplicación se ejecute, incluidas las bibliotecas, las dependencias y el código. Docker es una herramienta poderosa que simplifica el proceso de desarrollo y despliegue de aplicaciones, lo que permite a los equipos de desarrollo trabajar de manera más eficiente y colaborativa. En este informe, exploraremos qué es Docker, cómo funciona y cómo se puede utilizar para mejorar el desarrollo y despliegue de aplicaciones.\\

En este articulo, discutiremos la arquitectura de Docker y varios componentes de Docker.\\

\section{¿Qué es Docker?}
\noindent
Quiero comenzar tratando de explicar de la manera más simple y sencilla qué es Docker y para que sirve, entregaré primero una definición muy fácil de entender y después otra más formal.\\
\noindent
Imaginate que tienes un juego al que quieres jugar en diferentes consolas, quieres jugarla en PS4, Xbox, Nintendo Switch, etc, pero cada consola tiene sus propias reglas y no puedes instalar el juego directamente. Ahora piensa en Docker como una \textbf{caja mágica} donde metes el juego junto con todos los requisitos que necesitas para jugarlo. \\
\noindent
Con esta caja mágica, no importa en qué consola lo pongas: siempre funcionará igual porque lleva consigo todo lo que necesitas para que funcione. Docker es esa caja mágica\\

\noindent
Docker es una herramienta que facilita el desarrollo, despliegue y ejecución de aplicaciones de manera fácil y eficiente utilizando \textbf{contenedores}. Un contenedor es como una caja que incluye todo lo que una aplicación necesita para funcionar: su código, librerías, dependencias y configuración. Esto asegura que la aplicación se ejecute de manera consistente sin importar el entorno en el que se utilice.\\

\newpage
\begin{center}
    \includegraphics[width=14cm]{imagendocker.png}
\end{center}
\noindent
Como se muestra en el diagrama anterior, múltiples aplicaciones se ejecutan en la máquina anfitriona. Cada aplicación se ejecuta en un contenedor separado. Cada contenedor tiene su propio sistema de archivos, bibliotecas y dependencias, lo que garantiza que las aplicaciones se ejecuten de manera aislada y segura. Por lo tanto, cada aplicación es independiente de las demás. Las aplicaciones no interfieren entre sí.\\

\noindent
Los contenedores de Docker se ejecutan sobre el sistema antifrión en un entorno aislado. No interfieren con el hardware del sistema anfitrión (a diferencia de las VM, que sí se comunican con el hardware). Por ejemplo, podemos tener un contenedor con una imagen de LINUX y ejecutarlo en un anfitrión con sistema operativo Windows.\\

\noindent
A continuación, está el \textbf{Docker Engine}. Docker Engine es una API utilizada por las aplicaciones para interactuar con el \textbf{Docker Daemon}. Docker Engine se utiliza para ejecutar el sistema operativo antifrión. Podemos acceder a Docker Engine usando cualquiera de los clientes HTTP. Aprenderemos más sobre Docker Engine más adelante.
